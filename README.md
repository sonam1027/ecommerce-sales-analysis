# E-commerce Sales Analysis

Data analysis project using Python (Pandas, Matplotlib, Seaborn).

## Dataset
10,000 synthetic e-commerce orders (practice dataset) with city, category, payment method, discounts, delivery days, ratings and returns.

## What I did
- Cleaned the data: duplicates, missing values, messy city names, invalid ages and impossible order amounts
- Explored revenue by category, month and city
- Analysed return rates by payment method, category and discount
- Turned charts into business insights

## Key findings
- Electronics generates ~66% of total revenue
- October and November are the peak months (festive season)
- Delhi, Mumbai and Bengaluru are the top cities by revenue
- Fashion (20%) and COD orders (15%) have the highest return rates
- Return rate rises with discount: 9% at no discount vs 15% at 40% off

## Files
- `ecommerce_sales_analysis.ipynb`: full analysis notebook
- `ecommerce_orders_10k.csv`: dataset
